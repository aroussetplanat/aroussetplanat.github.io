# adrienroussetplanat.com

Source of [adrienroussetplanat.com](https://adrienroussetplanat.com), built with Jekyll on GitHub Pages.

- Home page: `_pages/about.md` (text and front matter) rendered by `_layouts/landing.html`, styled by `assets/css/landing.css`
- Papers: one file per paper in `_publications/` — `category` (`wp` or `work_in_progress`), `order`, `title`, `tagline`, `coauthors`, `abstract`, `latest_draft` (PDF in `files/pdf/research/`) and optional `links`
- News: `_data/news.yml`, newest first
- Visit counts: set `goatcounter` in `_config.yml`
